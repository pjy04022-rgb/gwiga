# 귀가약속

술자리 **전·끝·다음 날 아침** 세 시점에 개입하는 음주운전 예방 웹앱입니다. 경찰학 캡스톤디자인 과제로 만들었습니다.

| 화면 | 하는 일 |
|---|---|
| 술자리 계획 | 맑은 정신일 때 귀가 방법을 정해 저장. 끝날 시간에 앱 화면·앱 알림·캘린더로 다시 알림 |
| 모임 | 총무가 모임을 만들어 링크를 보내면, 참가자는 각자 휴대폰에서 귀가 방법을 정해야 참가. 차를 가져온 사람은 친구가 키를 확인할 때까지 미확인, 미확인 0명이어야 마무리 |
| 서약 카드 | 약속을 카드 이미지와 문구로 만들어 친구에게 공유 |
| 숙취 계산 | 위드마크 공식으로 운전 예정 시각의 혈중알코올농도를 보수적으로 추정 (판정하지 않음) |
| 처벌·단속 | 도로교통법 [시행 2026. 10. 13.] 기준 수치별 처벌과 단속 절차 |

설치 없이 휴대폰 브라우저로 열 수 있고, 홈 화면에 추가하면 앱처럼 쓰고 오프라인에서도 열립니다. 입력한 내용은 그 기기에만 저장됩니다.

## 내 컴퓨터에서 실행

```bash
cd gwiga-app
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다. (파일을 더블클릭해 열면 오프라인 기능이 꺼집니다.)

## 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub에서 새 저장소(예: `gwiga`)를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save.
3. 1~2분 뒤 `https://<아이디>.github.io/gwiga/` 주소가 생깁니다. 이 주소를 제출하면 됩니다.

Claude Code에서는 이렇게 부탁하면 됩니다: "이 폴더를 GitHub 저장소 gwiga로 올리고 GitHub Pages로 배포해줘."

## 휴대폰 홈 화면에 추가

- 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
- 갤럭시(Chrome·삼성 인터넷): 메뉴 → **홈 화면에 추가** 또는 **앱 설치**

## 안드로이드 앱

같은 화면을 설치형 앱으로도 쓸 수 있습니다. 알림이 가장 확실하게 뜹니다.

- 받기: 휴대폰에서 **https://github.com/pjy04022-rgb/gwiga/releases/latest/download/gwiga.apk** 열기 → 설치
  (처음 한 번 "출처를 알 수 없는 앱 설치"를 허용해야 합니다. 갤럭시에서는 웹앱의 술자리 계획 화면에도 "안드로이드 앱 받기"가 보입니다.)
- main에 새 버전을 올리면 GitHub가 자동으로 새 APK를 만들어 같은 주소에 올립니다. 받아서 설치하면 기존 앱 위에 업데이트됩니다.
- 빌드 방법은 `app/README.md`에 있습니다.

## 앱 받기 · 업데이트

- 휴대폰으로 웹 주소를 처음 열면 그 휴대폰에 맞는 설치 안내가 뜹니다. 위쪽 **앱 받기** 버튼으로 언제든 다시 열 수 있고, 안드로이드·아이폰 안내를 바꿔 볼 수 있습니다.
- 웹은 GitHub에 올리면 다음에 열 때 바로 새 버전이 보입니다.
- 설치한 앱은 GitHub에 새 버전이 올라오면 앱을 열 때 "새 버전이 나왔습니다"로 알려 줍니다.

## 아이폰

아이폰은 웹에서 앱 파일을 바로 설치할 수 없습니다(App Store는 Apple Developer Program 가입 필요). 그래서 두 가지를 안내합니다.

- **홈 화면에 추가 (권장)**: Safari로 웹 주소를 열고 공유 버튼 → **홈 화면에 추가**. 앱처럼 아이콘으로 열리고, iOS 16.4 이상이면 그 아이콘으로 열었을 때 알림을 허용할 수 있습니다(열어 둔 동안 울림). 아이폰으로 웹 주소를 열면 이 방법이 화면 위쪽에 안내됩니다.
- **설치 파일(.ipa)**: https://github.com/pjy04022-rgb/gwiga/releases/download/ios/gwiga.ipa — 컴퓨터에서 Sideloadly 같은 도구로 본인 Apple ID로 서명해 설치합니다. 무료 Apple ID는 7일마다 다시 설치해야 하며, 이렇게 설치하면 앱을 꺼 두어도 알림이 울립니다. 자세한 방법은 `app/README.md`.

## 알림

| | 안드로이드 앱 | 웹(브라우저·홈 화면) |
|---|---|---|
| 술자리 끝나기 15분 전·끝날 시간 | 앱을 꺼 두어도 정확한 시각에 화면 위로 | 탭이 열려 있을 때만 |
| 다음 날 운전 30분 전 숙취 확인 | 앱을 꺼 두어도 | 탭이 열려 있을 때만 |
| 모임: 차 키 미확인이면 30분 전, 끝날 시간 | 앱을 꺼 두어도 | 탭이 열려 있을 때만 |
| 알림을 누르면 | 그 화면(약속·모임·숙취 계산)이 열림 | 같음 |

- 약속을 저장하거나 모임을 만들고 참가하는 순간 알림 허용을 묻습니다. 술자리 계획 화면 위쪽에 "몇 시에 울리는지"와 막힌 이유가 표시됩니다.
- 웹에서 탭을 닫아도 받으려면 **구글 캘린더** 또는 **휴대폰 캘린더(.ics)**에 추가하세요.
- 끝날 시간이 지난 뒤 앱을 다시 열면 약속 화면이 먼저 열립니다.

## 모임 모드

1. 총무가 **모임** 탭에서 모임 이름과 시간을 정해 만들고, **참가 링크**를 단체방에 보냅니다. 총무도 마시면 **나도 참가자로 등록하기**를 누릅니다.
2. 링크를 받은 사람은 별명, 귀가 방법, 차 여부를 **모두 골라야** 참가할 수 있습니다.
3. 차를 가져온 사람은 함께 있는 친구에게 키를 맡기고, 친구가 자기 휴대폰에서 **받았어요**를 눌러야 확인됩니다. 대리운전이면 끝난 뒤 **대리 기사 만났어요**를 누릅니다.
4. 확인 전에는 총무 화면에 **미확인**으로 남고, 그 사람은 **집에 도착했어요**를 누를 수 없습니다.
5. 술자리가 끝나고 미확인이 0명이어야 총무가 **모임 마무리**를 할 수 있습니다.

이 규칙은 화면뿐 아니라 서버(`supabase/schema.sql`)에서도 검사합니다. 서버 설정 방법은 `supabase/README.md`에 있습니다. `js/config.js`가 비어 있으면 모임 모드는 한 기기 안에서만 동작하는 시연판으로 열립니다.

## 점검

```bash
node tools/check.mjs            # 숙취 계산식·모임 규칙 점검
python3 tools/build_artifact.py # claude.ai 아티팩트용 단일 파일(dist/artifact.html)
```

## 설계 원칙

- 어떤 수치가 나와도 "운전해도 된다"고 판정하지 않습니다.
- 숙취 계산은 분해가 느린 사람 기준으로 추정하고, 적용한 가정을 모두 밝힙니다.
- 이름, 연락처, 위치를 수집하지 않습니다.

교육용 정보이며 법률 자문이 아닙니다. 법령은 국가법령정보센터(law.go.kr)에서 현행 조문을 확인하세요.
