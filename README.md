# 귀가약속

술자리 **전·끝·다음 날 아침** 세 시점에 개입하는 음주운전 예방 웹앱입니다. 경찰학 캡스톤디자인 과제로 만들었습니다.

| 화면 | 하는 일 |
|---|---|
| 술자리 계획 | 맑은 정신일 때 귀가 방법을 정해 저장. 끝날 시간에 앱 화면·앱 알림·캘린더로 다시 알림 |
| 모임 | 총무가 모임을 만들면 참가자 모두 귀가 방법을 정해야 참가. 차를 가져온 사람은 친구가 키를 확인할 때까지 미확인, 미확인 0명이어야 마무리 (현재 한 기기 시연판) |
| 서약 카드 | 약속을 카드 이미지와 문구로 만들어 친구에게 공유 |
| 숙취 계산 | 위드마크 공식으로 운전 예정 시각의 혈중알코올농도를 보수적으로 추정 (판정하지 않음) |
| 처벌·단속 | 도로교통법 [시행 2026. 10. 13.] 기준 수치별 처벌과 단속 절차 |

설치 없이 휴대폰 브라우저로 열 수 있고, 홈 화면에 추가하면 앱처럼 쓰고 오프라인에서도 열립니다. 입력한 내용은 그 기기에만 저장됩니다.

## 내 컴퓨터에서 실행

```bash
cd gwiga-app
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다. (파일을 더블클릭해 열면 오프라인 기능이 꺼집니다.)

## 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub에서 새 저장소(예: `gwiga`)를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save.
3. 1~2분 뒤 `https://<아이디>.github.io/gwiga/` 주소가 생깁니다. 이 주소를 제출하면 됩니다.

Claude Code에서는 이렇게 부탁하면 됩니다: "이 폴더를 GitHub 저장소 gwiga로 올리고 GitHub Pages로 배포해줘."

## 휴대폰 홈 화면에 추가

- 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
- 갤럭시(Chrome·삼성 인터넷): 메뉴 → **홈 화면에 추가** 또는 **앱 설치**

## 알림에 대해

웹앱은 앱이 완전히 꺼진 상태에서 정해진 시각에 알림을 보내기 어렵습니다. 그래서 세 가지를 함께 씁니다.

1. **캘린더에 추가** (가장 확실): 구글 캘린더 또는 휴대폰 기본 캘린더(.ics)에 끝날 시간 일정을 넣어, 캘린더가 알림을 울립니다. 다음 날 운전 예정이면 운전 30분 전 "숙취 확인" 일정도 함께 들어갑니다.
2. **앱 알림**: 앱이 켜져 있거나 백그라운드에 있을 때 끝날 시간에 알림을 띄웁니다.
3. **앱 화면**: 끝날 시간이 지난 뒤 앱을 열면 약속이 맨 위에 다시 뜹니다.

## 모임 모드 시연 방법

1. **모임** 탭 → **예시 모임 열기**
2. 위쪽 시연 막대에서 **끝날 시간으로 건너뛰기** → 미확인 3명 때문에 **모임 마무리**가 막힌 것을 확인
3. **누구 화면으로 볼까요**에서 민수 → "받았어요", 준 → 서연에게 키 맡기기, 서연 → "받았어요", 지현 → "대리 기사 만났어요"
4. 총무 화면으로 돌아오면 미확인 0명, **모임 마무리**가 열림
5. **새 참가자로 참가해 보기**로 세 항목을 모두 골라야 참가되는 것을 확인

지금은 한 기기 안에서만 동작합니다. 여러 사람이 각자 휴대폰으로 쓰려면 서버 연결이 필요하며, 방법은 `CLAUDE.md`의 "다음 단계"에 적어 두었습니다.
